# Security

ToolZen Desktop processes files on the device. It does not upload them and it does not phone home.

Report a vulnerability privately to the repository owner. Do not open a public issue with exploit details until a fix is available.

This project does not claim to be free of vulnerabilities. See [docs/SECURITY-AUDIT.md](docs/SECURITY-AUDIT.md) for the current review, including what was checked and what remains.
