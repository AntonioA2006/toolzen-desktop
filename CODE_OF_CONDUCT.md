# Code of conduct

Contributors are expected to:

- Focus on the technical problem.
- Assume good faith and disagree specifically.
- Keep reviews about the change, not the person.
- Avoid harassment, slurs, and personal attacks.

Maintainers may reject changes or close discussions that break these expectations. This is a project policy, not a certification or an affiliated organization's code.
